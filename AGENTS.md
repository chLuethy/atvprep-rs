## Agent skills

### Issue tracker

Issues live in GitHub (`chLuethy/atvprep-rs`), accessed via the `gh` CLI. Gitea (`chl/atvprep-rs` on git.ch-luethy.ch) is only a release mirror: never file issues, PRs or pushes there (ADR 0009). See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Sprache

Alle vom Agenten verfassten Texte (Issues, Specs, Kommentare, PRs, Commit-Messages, Glossar, ADRs) sind auf Deutsch; Code, Bezeichner und Label-Namen bleiben englisch. Siehe `docs/agents/language.md`.
