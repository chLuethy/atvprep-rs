# Gestaltungsreferenz des Managers

`manager-mockup.html` ist das funktionierende Mockup des Managers auf Basis des persönlichen Designsystems „Christian Lüthy“ (Kupfer als einzige Farbe, Radius 0, Haarlinien, gestrichelte Spaltenlinien, Helvetica und JetBrains Mono, Hell/Dunkel/System). Es ist eine einzelne HTML-Datei ohne Abhängigkeiten: im Browser öffnen, über `#dateien`, `#aktivitaet`, `#zeitplaene`, `#uebersicht` und `#einstellungen` zwischen den Seiten wechseln.

Das Mockup legt Aussehen, Abstände, Raster und das Verhalten bei schmalen Fenstern fest. Daten und Abläufe darin sind simuliert; massgeblich für Verhalten bleibt der Manager selbst. Die Umsetzung ist in einem GitHub-Issue (Label `ready-for-agent`) beschrieben.
