# Sprache

Alle vom Agenten verfassten Texte sind auf **Deutsch**:

- Issues (Titel, Body), Specs, Tickets, Kommentare, Triage-Notizen
- PR-Titel und PR-Beschreibungen
- Commit-Messages (ab jetzt; bestehende Commits bleiben unverändert)
- `GLOSSARY.md` und ADRs
- Antworten und Berichte an den Nutzer

**Englisch bleiben:**

- Code, Bezeichner, Code-Kommentare und Fehlermeldungen im Code
- Label-Namen (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`, `wayfinder:*`)
- Maschinell ausgewertete Marker wie `Part of #<n>` und `Blocked by: #<n>`
- Das Conventional-Commit-Präfix (`fix:`, `feat:`, `refactor:` …); die Beschreibung danach ist deutsch

Fachbegriffe richten sich nach `GLOSSARY.md`. Skill-Vorlagen mit englischen Überschriften (z. B. `## Language` im Glossar) werden mit deutschem Inhalt gefüllt.
