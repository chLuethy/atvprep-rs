# Rust-Workspace

`./rust/check.sh` prüft Formatierung, Clippy, Tests und Abhängigkeiten. `cargo test --locked --workspace --manifest-path rust/Cargo.toml` führt die Tests mit den eingecheckten Referenzdaten aus. Weitere Hinweise stehen im [README](../README.md) und in der [Betriebsanleitung](../DEPLOYMENT.md).
